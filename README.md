## My Approach

I approach automation from both a **business and technical perspective**.

**Business Problem → Requirements → Process Analysis → Solution Design → AI / Automation → Testing → Improvement**

The objective is not simply to automate a task. I first consider:

- What business problem needs to be solved?
- Which manual steps are repetitive or inefficient?
- What information is required to make a decision?
- Which decisions can be handled using business rules?
- Where can AI provide additional value?
- Where should human review or approval remain?
- How can the solution be made reliable and maintainable?

This approach allows me to bridge the gap between **business requirements and technical implementation**.
